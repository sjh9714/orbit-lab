# ORBIT LAB · Miniature Collection

아이보리 금속과 주황색 포인트를 공유하는 다섯 탐사 모델을 직접 조종합니다. Three.js로 모델과 행성 테스트장을 생성하며 외부 모델·이미지·텍스처·폰트를 요청하지 않습니다.

## 실행

Node.js 22.12 이상의 22.x 버전을 사용합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. `npm run build`는 정적 파일을 `dist/`에 생성하고 `npm run preview`는 빌드 결과를 제공합니다.

## 배포

Vercel은 `vercel.json`에 따라 Node.js 22.x에서 `npm ci`와 `npm run build`를 실행하고 `dist/`를 배포합니다. 환경 변수나 별도 서버가 필요하지 않습니다.

연결된 프로젝트를 수동으로 운영 배포하려면 `vercel --prod`를 실행합니다. 로컬 출력물, 브라우저 검사 결과, Vercel 연결 정보와 환경 파일은 저장소·배포 소스에서 제외합니다.

## 직접 조종

기본 모드는 **직접 조종**입니다. 화면을 누르거나 Tab으로 캔버스에 포커스를 두고 조종합니다. WASD와 방향키를 모두 지원합니다.

조종 모델 선택, 직접 조종 모드 진입, 조종 재개, 전체 초기화 직후에는 키보드 입력이 캔버스로 연결됩니다. 다른 UI에 포커스가 있을 때는 일반 버튼 동작을 유지하며, 조종 패널의 연결 상태 안내로 입력 대상을 확인할 수 있습니다. 드론은 Space 또는 상승 버튼을 누르고 먼저 이륙해야 수평으로 이동합니다. 화면 방향·상승·하강 버튼은 누르는 동안 작동합니다.

| 모델 | 방향 입력 | Space | Shift | 모션 |
| --- | --- | --- | --- | --- |
| ORBIT–01 | 카메라 기준 걷기 | 점프 | — | 발 접지 IK, 팔 흔들기, 준비·도약·착지, 인사 |
| ROVER–02 | W/S 전후진, A/D 선회 | 제동 | — | 주행·선회에 연동한 여섯 바퀴, 마스트 관성 |
| SCOUT–03 | 카메라 기준 수평 이동 | 누르는 동안 상승 | 하강 | 프로펠러 가감속, 기체 기울기, 짐벌 보정 |
| LANDER–04 | 낮은 추진 도약으로 이동 | 높은 추진 도약 | — | 엔진 분사, 레이더 탐색, 착지 완충 |
| RELAY–05 | 카메라 기준 관성 이동 | 상승 | 하강 | 자세 제어 분사, 패널 추적 |

로봇은 2m/s·1m 점프, 로버는 2m/s, 드론은 수평 3m/s·수직 2m/s·고도 0~6m로 제한합니다. 착륙선은 1.4m/s이며 일반 도약 0.35m·높은 도약 1.2m입니다. 위성은 1.5m에서 시작하고 수평 2.2m/s·수직 1.2m/s·고도 1~6m이며 입력을 놓으면 약 2초에 걸쳐 감속합니다. 모델 크기를 반영해 반경 12m 밖으로 나가지 않게 합니다.

- **드래그**로 추적 카메라 방향을 바꾸고 **스크롤·핀치·+/−**로 확대·축소합니다.
- 화면의 **방향 패드와 동작 버튼**도 같은 입력을 보냅니다. 여러 손가락으로 이동과 점프·상승을 동시에 누를 수 있습니다.
- **일시정지**는 현재 자세와 위치를 멈춥니다. 조종 재개 버튼이나 새 방향·동작 입력으로 재개합니다.
- 창을 벗어나거나 탭이 숨겨지면 입력을 해제하고 일시정지합니다. 캔버스 밖의 버튼과 페이지는 일반 키보드 동작을 유지합니다.
- **R / 전체 초기화**, 모델 전환, 모드 전환은 위치·속도·관절·카메라를 초기 상태로 복원합니다.

## 감상과 내보내기

**모델 감상**에서는 모델을 회전·확대하며 살펴보고 기존 부품 동작과 자동 회전을 재생할 수 있습니다. 이 모드의 캔버스 방향키는 시점 회전, Space는 부품 동작 시작·멈춤입니다.

다섯 모델은 공통 도장·금속·고무·광학 유리 재질을 사용합니다. 고정 시드로 생성한 128px 거칠기·노멀 텍스처가 가까운 거리에서만 미세한 표면 차이를 만듭니다. 감상 모션에는 관측·인사 사이의 정지 구간이 있으며 재생·일시정지·초기화에 함께 반응합니다.

## 사진 스튜디오

**사진 모드**는 현재 부품 포즈를 복제하고 조종과 감상 동작을 멈춥니다. 드래그·스크롤·핀치로 구도를 조절하거나 전신·주요 장비·후면 구도를 선택합니다. 웜 스튜디오·쿨 스튜디오·림 라이트는 감상 모드에서도 선택할 수 있습니다.

- 비율: 16:9, 1:1, 4:5. 미리보기에도 선택한 비율이 적용됩니다.
- PNG: 긴 변 2048px 또는 3840px. 기본값은 16:9·2048px입니다.
- 노출: 0.60~1.60배. 미리보기와 저장 파일은 동일한 색 변환을 사용합니다.
- 별도 HDR 렌더 타깃으로 UI 없이 촬영하며, 실패하면 설정을 유지한 채 재시도하거나 2048px로 낮춰 저장할 수 있습니다.
- 촬영 종료 시 원래 모델 위치·부품 포즈·시점으로 돌아가며 일시정지를 유지합니다. 조종 재개 또는 감상 동작 시작으로 움직임을 재개합니다.

## GLB 내보내기

**GLB 다운로드**는 선택한 모델의 현재 부품 자세를 저장합니다. 탐사장 위치와 방향, 바닥·배경·조명·카메라·추진 효과는 포함하지 않습니다. 파일 생성 중 모델 선택을 잠시 막으며 실패하면 같은 버튼으로 다시 시도할 수 있습니다.

파일 이름은 `orbit-01.glb`, `rover-02.glb`, `scout-03.glb`, `lander-04.glb`, `relay-05.glb`입니다. 단위는 미터이며 Y축이 위쪽입니다. 부품 이름·관절 계층·재질·생성 텍스처·현재 자세를 보존합니다. **브라우저 모션은 GLB 애니메이션 클립으로 저장하지 않습니다.** 관절은 이름 있는 Group으로 구성한 강체 관절이며 스킨 리깅이 아닙니다. 렌즈는 transmission·IOR·clearcoat 재질 확장을 사용합니다.

## 구조

- `src/catalog.js`, `src/models/`, `src/robot.js`: 모델 생성과 부품 모션. `createModel(id)`는 `{ root, update(deltaSeconds, motionState), reset(), effects? }`를 반환합니다. effects는 root와 별도로 actor에 붙여 내보내기에서 제외합니다.
- `src/motion.js`: 렌더링과 독립된 1/60초 고정 간격 이동 계산, 가감속·점프·고도·경계 판정.
- `src/input.js`: 키보드·다중 포인터 입력 및 해제 처리.
- `src/viewer.js`, `src/terrain.js`: 추적 카메라, 월드 이동, 탐사장과 조명·그림자, 조종·감상 모드.
- `src/main.js`, CSS, `index.html`: 한국어 안내·반응형 조작·모델 선택·오류 처리.
- `src/export.js`: 모델 root를 복제한 별도 장면에서 GLB 생성.
- `src/materials.js`: 모델별 소유권을 갖는 공통 재질·절차 텍스처 생성.
- `src/studio.js`: 전시대·조명·반사 환경·형태 기반 접촉 그림자. 모델 리소스는 해제하지 않습니다.
- `src/photo.js`: 포즈 복제, 촬영 카메라, 미리보기와 PNG 색 변환·렌더 타깃. 촬영 복제본은 모델 재질·지오메트리를 공유하며 자체 해제하지 않습니다.

`motionState`는 모드, 시간, 위치·속도·방향, 실제 이동 거리, 접지 여부, 수직 속도, 동작 단계와 웅크림·착지·추력을 전달합니다. 월드 이동은 viewer의 actor가 담당하고 각 모델은 내부 부품만 움직입니다. 일시정지와 정지된 감상 화면은 필요할 때만 렌더링합니다.

## 검증

```sh
npx playwright install chromium
npm test
npm run build
```

WebKit에서도 동일한 브라우저 흐름을 검사하려면 다음 명령을 실행합니다. Chromium 전용 디버깅 프로토콜을 사용하는 다중 터치·핀치 검사는 기본 `npm test`에 포함됩니다.

```sh
npx playwright install webkit
npm run test:webkit
```

순수 이동 계산을 30·60·120fps 입력 간격으로 비교하고 실제 Chromium에서 주요 조종 흐름을 검증합니다. 320~3840px의 대표 크기 13종을 조종·감상 모드 각각 검사하며, 모바일 가로·세로 화면, 터치·핀치·동시 입력, 입력 해제, 초기화, GLB 재로딩, 다운로드·WebGL 오류 복구를 포함합니다. GLB는 메시·삼각형 수, 재질, 부품 이름·계층·변환, 경계 크기를 원본과 비교합니다. 오류 복구 테스트가 의도적으로 발생시킨 오류는 테스트 출력에 나타납니다.

사진 검사는 세 비율·두 해상도의 PNG 크기·방향·색상, 조명·구도, 사진 종료 후 상태 복원과 저장 재시도를 포함합니다. 생성 텍스처는 GLB에 포함된 이미지의 실제 픽셀과 재질 슬롯·UV 설정까지 다시 불러와 비교합니다.

입력 흐름 검사는 캔버스를 강제로 포커스하지 않고 실제 모델 선택·재개 버튼에서 시작합니다. 키보드 연결, 일반 버튼의 Space 동작, 마우스 홀드, 창 이탈, 드론 동시 터치와 촬영 후 조종 복귀, 카메라 관성이 남은 상태에서의 사진 복귀를 포함합니다.
